# Third-party data

lumos contains no third-party code. It contains data from these sources.

## Unicode case folding

`src/md/unicode_tables.inc` is generated by `tools/gen_unicode_tables.py`
from `CaseFolding.txt` 17.0.0 of the Unicode Character Database, and from
the Unicode 15.0.0 general categories in Python's `unicodedata`.

License: Unicode License v3 (https://www.unicode.org/license.txt).
Copyright © 1991-2025 Unicode, Inc.

## HTML entity names

`src/md/entity_table.inc` is generated by `tools/gen_entity_table.py` from
the WHATWG list of HTML named character references
(https://html.spec.whatwg.org/entities.json), as Python's
`html.entities.html5` holds it.

License: Creative Commons Attribution 4.0 International
(https://creativecommons.org/licenses/by/4.0/).
Copyright © WHATWG (Apple, Google, Mozilla, Microsoft).

## Spec test files

`tests/spec/commonmark-0.31.2.txt`, `tests/spec/gfm-0.29.txt` and
`tests/spec/extensions.txt` are copies of the CommonMark spec, the GitHub
Flavored Markdown spec and the cmark-gfm extension tests.
`tests/spec/README.md` names their sources and commits.

License: Creative Commons Attribution-ShareAlike 4.0 International
(https://creativecommons.org/licenses/by-sa/4.0/). The CommonMark spec is
Copyright © 2014-16 John MacFarlane. The share-alike terms apply to these
files only, not to the code that reads them.

## Regex library

Regex find links the system PCRE2 library (BSD 3-Clause License with the
PCRE2 exception). It is not part of this repository.

## Test library

The tests use Catch2 (Boost Software License 1.0), fetched from GitHub at
configure time. It is not part of this repository.
